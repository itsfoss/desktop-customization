## Zellij Themes

This is a set of themes to use inside the Zellij terminal multiplexer.

To apply, download and paste the themes inside a directory called `~/.config/zellij/themes`.

Now, inside the Zellij config file `config.kdl`, add this line:

```
theme "lavender-fields-light"
```

Change the name of the theme to the one you want to use.
