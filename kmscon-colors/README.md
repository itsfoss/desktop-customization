## How to Apply
Create the kmscon config file at `/etc/kmscon/kmscon.conf`. Open it in an editor with sudo.

```
sudo nano /etc/kmscon/kmscon.conf
```

Copy the contents of the colorscheme of your choice and paste it in the config file.

> Note: You only need to have one `palette=custom` line in the config.

Save the file and exit the editor. New TTY screens opening will use the new color scheme.
