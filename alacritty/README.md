## Alacritty Config Files

This is a sample config file for Alacritty

Requirements:

- JetBrains Mono Font

There are several color schemes available in the themes directory.

Also there is an `alacritty.toml` and a `keybindings/keybindings.toml`. You can use this `alacritty.toml` as a quick config file for alacritty, that will use the catppuccin-mocha color scheme.

Change the name of the color scheme in the `import` statement to another to change the color scheme of Alacritty.

These color schemes are created by third-party, like Catppuccin, Dracula, etc.
